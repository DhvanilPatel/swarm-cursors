# @swarm-cursors/react

Optional React bindings for `swarm-cursors`. Install React and the core package as peers, then import from `swarm-cursors/react` or `@swarm-cursors/react`.

The `SwarmProvider` and `SwarmRebuild` components initialize after mount and clean up on unmount. `useSwarm` accesses the nearest provider; `useSwarmEvents` subscribes and returns cleanup through the React effect lifecycle.
